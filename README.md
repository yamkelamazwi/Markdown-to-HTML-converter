## Description

A responsive Markdown to HTML Converter built with JavaScript and Regular Expressions. The application transforms Markdown syntax into HTML in real time while displaying both the generated HTML code and a live rendered preview.

This project demonstrates DOM manipulation, event handling, regular expressions, dynamic content rendering, and responsive user interface design.

## Features

- Real-time Markdown conversion
- Live HTML preview
- Raw HTML output display
- Character counter
- Copy HTML button
- Clear editor button
- Responsive design
- Spotify-inspired interface

### Supported Markdown Syntax

#### Headings

```md
# Heading 1
## Heading 2
### Heading 3
```

#### Bold Text

```md
**Bold Text**
```

or

```md
__Bold Text__
```

#### Italic Text

```md
*Italic Text*
```

or

```md
_Italic Text_
```

#### Images

```md
![Alt Text](image-source)
```

#### Links

```md
[GitHub](https://github.com)
```

#### Blockquotes

```md
> This is a quote
```

## How It Works

The application listens for user input inside the Markdown editor and uses regular expressions to detect Markdown patterns and convert them into their HTML equivalents.

Example:

### Markdown Input

```md
# Yamkela Mazwi

**Frontend Developer**

*Building JavaScript Projects*

> Learning one project at a time
```

### Generated HTML

```html
<h1>Yamkela Mazwi</h1>

<strong>Frontend Developer</strong>

<em>Building JavaScript Projects</em>

<blockquote>Learning one project at a time</blockquote>
```
