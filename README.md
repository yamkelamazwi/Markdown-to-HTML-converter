A real-time Markdown to HTML converter that transforms Markdown syntax into HTML while displaying both the generated HTML code and a live rendered preview.

## Live Demo

[Live Demo](YOUR_GITHUB_PAGES_LINK)

## Features

- Real-time Markdown to HTML conversion
- Live HTML preview
- Raw HTML output display
- Converts headings (`#`, `##`, `###`)
- Converts bold text (`**text**`, `__text__`)
- Converts italic text (`*text*`, `_text_`)
- Converts images
- Converts hyperlinks
- Converts blockquotes
- Character counter
- Copy HTML button
- Clear editor button
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Regular Expressions
